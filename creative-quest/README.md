# Creative Quest — Prototype v0.1

Egyptian Arabic Creative Thinking game with nine interactive Observation exercises and one Boss challenge. Responsive, static, no API subscription. XP and progression use browser Local Storage. The normal-level evaluator is keyword-based and can miss valid answers; players may self-review after two attempts. Boss Level 10 copies a structured prompt for ChatGPT and has **manual, unverified** result entry. Territory doors are a preview only; the remaining 490 levels are not implemented yet.

Play: https://mahmoud-abd-elwahab.github.io/portfolio/creative-quest/
