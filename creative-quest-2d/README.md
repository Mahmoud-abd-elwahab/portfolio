# Creative Quest 2D — v0.2

Playable mobile-first top-down 2D game with joystick/tap-to-walk, a character moving on an explorable map, 9 new Observation challenges, one three-shield boss, XP, level progression, browser-local saves, and locked previews for Tension, Insight, and Territory worlds.

The first world only is implemented; the full 500 levels are not. Answers are evaluated via limited local keyword logic, with a self-assessment fallback after two tries. Boss can open ChatGPT and copies the challenge; return is manual, no authenticated automated grade. No paid API.

Live path: https://mahmoud-abd-elwahab.github.io/portfolio/creative-quest-2d/
